# Topo AI — анализ топографических карт

Программа на Python для работы с топографическими картами (PDF или изображения): измерение расстояний, поиск высот, определение координат объектов.

---

## 📌 Что делает эта программа

Topo AI — это набор инструментов для анализа топографических карт. Программа умеет:

| Команда | Что делает |
|---|---|
| **`info`** | Накладывает координатную сетку на карту, выделяет линии, распознаёт числа-высоты |
| **`measure`** | Считает расстояние между двумя точками в метрах |
| **`pixels`** | Считает расстояние в пикселях и переводит его в метры на пиксель (для калибровки) |
| **`objects`** | Находит объекты (замкнутые контуры) и выводит их координаты центров |
| **`pick`** | Создаёт HTML-страницу, где можно кликать по карте и получать координаты точек |

Пример работы:

```bash
python topo_ai.py measure --file semka.jpg --p1 300,200 --p2 600,400 --meters-per-px 0.0847
```

Результат:

```
Точка 1: (300, 200)
Точка 2: (600, 400)
Расстояние: 360.6 px = 30.54 м
Визуализация сохранена: semka_measure.png
```

## 🧠 Как это работает — по шагам

### 1. Загрузка карты

Программа принимает **PDF** или **изображение** (JPG, PNG). Если файл PDF, он автоматически конвертируется в изображение при 300 DPI.

### 2. Команда `info` — подготовка карты

Что происходит:

1. **Накладывается сетка** через каждые 100 пикселей с красными подписями координат (`semka_grid.png`) — по ней вы считываете координаты нужных точек.
2. **Выделяются линии** через OpenCV (`semka_edges.png`) — кандидаты в горизонтали, дороги, границы.
3. **Распознаются числа** через EasyOCR — программа находит все числовые подписи (например, «285,19») и выводит их с координатами.

### 3. Команда `measure` — измерение расстояний

Вы задаёте две точки `x,y` и масштаб (`--meters-per-px`, `--scale` + `--dpi` или через опорный отрезок). Программа:

1. Считает расстояние между точками в пикселях (по теореме Пифагора).
2. Умножает на масштаб → получает метры.
3. Рисует линию между точками на карте и подписывает расстояние (`semka_measure.png`).

### 4. Команда `pick` — интерактивный выбор точек

Создаёт HTML-страницу с картой. Кликаете по карте мышкой — справа появляются координаты `x,y`. Кнопка «Скопировать все» копирует список в буфер обмена.

### 5. Команда `objects` — поиск объектов

Находит все замкнутые контуры на карте (здания, пятна, замкнутые горизонтали) через OpenCV. Для каждого объекта выводит **центр `(x, y)`**, площадь и ограничивающий прямоугольник.

## 📋 Команды и примеры

### `info` — анализ карты

```bash
python topo_ai.py info --file semka.jpg
```

Что создаёт:

- `semka_grid.png` — карта с координатной сеткой;
- `semka_edges.png` — выделенные линии.

Вывод в терминале:

```
Загрузка: semka.jpg
Размер: 1416×672 px
Сетка сохранена: semka_grid.png
Линии сохранены: semka_edges.png
Найдено отметок высот: 47
  285.19 м  @ (342, 891)   conf=0.94
  284.53 м  @ (678, 1204)  conf=0.91
  ...
```

**Сохранить высоты в JSON:**

```bash
python topo_ai.py info --file semka.jpg --save-json heights.json
```

---

### `measure` — измерить расстояние

Три способа задать масштаб:

**Способ А: знаете метры на пиксель**

```bash
python topo_ai.py measure --file semka.jpg --p1 300,200 --p2 600,400 --meters-per-px 0.0847
```

**Способ Б: знаете масштаб карты и DPI**

```bash
python topo_ai.py measure --file semka.jpg --p1 300,200 --p2 600,400 --scale 1000 --dpi 300
```

**Способ В: знаете реальное расстояние между двумя точками (калибровка)**

Допустим, между точками `(100,100)` и `(400,100)` по карте ровно 25 метров:

```bash
python topo_ai.py measure --file semka.jpg \
    --p1 300,200 --p2 600,400 \
    --real 25 --real-from 100,100 --real-to 400,100
```

**Результат:** расстояние в метрах + файл `semka_measure.png` с линией и подписью.

---

### `pixels` — расстояние в пикселях и калибровка

Помогает узнать `м/px`, если на карте есть масштабная линейка или километровая сетка.

**Пример:** между двумя соседними линиями сетки на карте 1000 метров:

```bash
python topo_ai.py pixels --p1 300,200 --p2 890,200 --real 1000
```

Вывод:

```
Расстояние в пикселях: 590.00
Известное реальное расстояние: 1000 м
→ Метров на пиксель: 1.6949

Используйте в measure:
  --meters-per-px 1.6949
```

---

### `objects` — найти объекты и их координаты

```bash
python topo_ai.py objects --file semka.jpg --min-area 50 --limit 30
```

Параметры:

- `--min-area` — минимальная площадь объекта в пикселях (отсекает мелочь);
- `--limit` — сколько объектов показывать.

Вывод:

```
Найдено объектов: 87
   №  центр (x, y)       площадь px²  bbox
   1  (  412,   156)         4820.5  [380,120,64,90]
   2  (  851,   903)         2130.2  [820,880,62,46]
   3  (  234,   671)          987.3  [220,650,28,42]
```

Создаёт `semka_objects.png` — карта с зелёными рамками и номерами объектов.

**Сохранить в JSON:**

```bash
python topo_ai.py objects --file semka.jpg --min-area 50 --save-json objects.json
```

---

### `pick` — клик по карте для получения координат

```bash
python topo_ai.py pick --file semka.jpg
```

Создаёт два файла:

- `semka_pick.html` — интерактивная страница;
- `semka_preview.jpg` — картинка для неё.

**Как открыть:**

1. Кликните на `semka_pick.html` в Explorer.
2. **Правая кнопка** → **Open Preview** (или значок предпросмотра).
3. Кликайте мышкой по карте — справа появляются координаты `#1: 320,450`, `#2: 780,1200`.
4. Кнопка **«Скопировать все»** — копирует список в буфер обмена.

Затем вставьте эти координаты в `measure`.

## 📐 Как определить масштаб

### Способ 1: масштаб карты + DPI

Формула:

```
м/px = (знаменатель масштаба / 100) × 2.54 / DPI
```

Таблица готовых значений:

| Масштаб | DPI 200 | DPI 300 | DPI 600 |
|---|---|---|---|
| 1:500 | 0.0635 | 0.0423 | 0.0212 |
| 1:1000 | 0.1270 | **0.0847** | 0.0423 |
| 1:2000 | 0.2540 | 0.1693 | 0.0847 |
| 1:5000 | 0.6350 | 0.4233 | 0.2117 |
| 1:10000 | 1.2700 | 0.8467 | 0.4233 |

**Важно:** если работаете с PDF, программа конвертирует его в 300 DPI → используйте `--dpi 300`.

### Способ 2: масштабная линейка или километровая сетка

Если DPI неизвестен — используйте команду `pixels`:

1. Откройте `semka_grid.png`.
2. Найдите масштабную линейку (например, «0–100 м») или две соседние линии километровой сетки.
3. Считайте координаты их краёв по сетке.
4. Выполните `pixels --p1 ... --p2 ... --real ...`.

Этот способ точнее и не зависит от DPI файла.

## 🖼️ Как подготовить карту

✅ **Хорошо:**
- Отсканированная карта в JPG или PNG;
- PDF-файл топосъёмки;
- Чёткие линии, контрастные подписи.

❌ **Плохо:**
- Сильно размытые сканы;
- Фото карты под углом (искажение перспективы);
- Рукописные пометки поверх чисел.

## 🏗️ Как устроен код

| Функция | Назначение |
|---|---|
| `load_image` | Загружает PDF или изображение |
| `add_grid` | Накладывает координатную сетку |
| `extract_heights` | Ищет числа через EasyOCR |
| `detect_contours` | Выделяет линии через OpenCV Canny |
| `cmd_info` | Режим info |
| `cmd_measure` | Режим measure |
| `cmd_pixels` | Режим pixels |
| `cmd_objects` | Режим objects |
| `cmd_pick` | Режим pick |

**Что используется:**

- **OpenCV** — обработка изображений, поиск контуров, рисование линий;
- **EasyOCR** — распознавание текста (русский + английский);
- **pdf2image** — конвертация PDF в изображения;
- **NumPy** — вычисление расстояний, работа с массивами.

## ❓ Частые проблемы

| Проблема | Причина | Решение |
|---|---|---|
| `ModuleNotFoundError` | Не установлены библиотеки | `pip install -r requirements.txt` |
| `FileNotFoundError` | Файл не загружен | Загрузите карту в Explorer, проверьте имя через `ls` |
| Карта в HTML не отображается | Нет preview-файла | Убедитесь, что `semka_preview.jpg` есть рядом с `semka_pick.html` |
| OCR долго работает | Первый запуск | Подождите 2–5 минут (скачивает модель) |
| Высоты находятся плохо | Плохой скан или рукописные цифры | Попробуйте другую карту с чёткими подписями |
| Неверные расстояния | Неправильный масштаб | Проверьте `--meters-per-px` через `pixels` по сетке |

## 🔬 Как проверить точность

1. Измерьте по карте расстояние между двумя точками километровой сетки (например, 1 км).
2. Выполните `pixels --real 1000` — получите `м/px`.
3. Выполните `measure` между теми же точками с этим `м/px`.
4. Если результат ≈ 1000 м — масштаб верный.
