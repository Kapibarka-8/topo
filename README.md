## 📝 Аннотация

В рамках учебной практики разработано веб-приложение **Topo AI**, предназначенное для автоматизации процесса оцифровки топографических карт. Программа решает задачу извлечения числовых отметок высот (методом оптического распознавания символов — OCR), их пространственной привязки к геодезическим пунктам и построения интерактивных 2D и 3D моделей рельефа. 

Приложение демонстрирует полный цикл обработки пространственных данных: от загрузки растрового изображения (скана или PDF) до выгрузки готовых векторных данных в ГИС-системы (QGIS, ArcGIS) в формате GeoJSON.

## 🎯 Введение и цели проекта

**Актуальность.** Традиционная оцифровка топографических карт вручную (обводка горизонталей, ввод отметок высот) требует больших временных затрат. Разработка инструментов на базе компьютерного зрения (Computer Vision) позволяет ускорить этот процесс в разы.

**Цель проекта:** Создание веб-приложения на языке Python, автоматизирующего поиск отметок высот на топографических картах и формирующего 3D-модели рельефа.

**Задачи:**
1. Реализовать загрузку карт в форматах PNG, JPG, PDF с автоматическим определением разрешения (DPI).
2. Интегрировать нейросеть EasyOCR для поиска текстовых меток высот.
3. Разработать алгоритм «привязки» (snap) распознанного текста к черным перекрестиям (пикетам) на карте.
4. Реализовать математический пересчет пиксельных координат в метрические с учетом масштаба и опорного пункта.
5. Создать интерактивный веб-интерфейс (Streamlit) для ручной корректировки данных, измерения расстояний и 3D-визуализации.
6. Обеспечить экспорт данных в ГИС-форматы.

## 🌟 Ключевые возможности

| Модуль | Описание возможностей |
|---|---|
| **Загрузка данных** | Поддержка PNG, JPG, JPEG, PDF. PDF-файлы автоматически рендерятся в изображения с высоким разрешением (300 DPI) через PyMuPDF. |
| **Определение DPI** | Автоматическое считывание метаданных изображения. Для PDF — расчет на основе физического размера страницы. |
| **Распознавание (OCR)** | Использование EasyOCR (русский + английский) для поиска чисел. Фильтрация шумов и ложных срабатываний по длине строки и диапазону высот (0–9000 м). |
| **Snap-to-Dot** | Умная привязка координат: программа не ставит точку на текст, а ищет ближайшую черную точку в радиусе 60 пикселей с помощью OpenCV. |
| **Ручная разметка** | Интерактивный клик по карте. Встроенный **Zoom** (для работы с тяжелыми файлами), режим ластика (удаление точек). |
| **2D-карта** | Инструмент «Осмотр точек» (получение атрибутов по клику) и «Измерение расстояний» (расчет дистанции в метрах между двумя кликами). |
| **3D-рельеф** | Интерполяция высот по методу триангуляции (SciPy) и построение интерактивной поверхности Plotly Surface. |
| **Экспорт** | Выгрузка в CSV, Excel (.xlsx) и GeoJSON (с переводом в локальные метрические координаты). |
